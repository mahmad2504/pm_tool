PCIe Drv Windows driver development for Altera FPGA PCIe DMA. Windows driver development for Altera FPGA PCIe DMA.

The FPGA PCIe DMA IP transfers large amounts of data between FPGA-side memory/logic and a Windows PC. The driver makes that hardware usable from Windows, covering device detection, configuration, BAR/register mapping, DMA buffer allocation, transfers, interrupts, and status. A user-space test application validates PC-to-FPGA and FPGA-to-PC DMA paths.
